# Archive

This folder holds historical and superseded documentation and records for
this repository — things like old plans, retired guides, or notes about
decisions and state that no longer apply.

**Nothing in this folder describes the current state of the project.**
Content here reflects a point in time: a plan that was later revised, a
process that has since changed, or a decision that has since been
superseded. It is kept for historical reference only.

Contributors and coding agents (including Claude) should treat everything
under `archive/` as historical context only — never as current truth, and
never as a basis for new work. If you need to understand how this repo
works today, look at the top-level `README.md` and the active docs outside
this folder, not anything in here.
